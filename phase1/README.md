# Phase 1 — four from-scratch legal language models

One folder per model (prefixlm, encdec, arch4, biscale), each with model.py, train.py, generate.py, pretokenize.py and the Kaggle/Colab notebook that ran it. `arch4/continue_arch4.ipynb` continued the retention run in a second session; `biscale/generate_colab` generated the Bi-Scale submission. See the top-level README for architectures and training settings.
